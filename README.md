# 请求滚动提示

每完成一次模型请求，就在 Codex 右下角弹出一条提示（模型、耗时、供应商、token、成败），新的从下面顶上来，旧的逐渐变淡消失。

## 安装

在 Codex++ 管理器打开「拓展 → 社区拓展」，搜索 `request-toasts` 点安装；
或从 [Releases](https://github.com/BigPizzaV3/codexpp-request-toasts/releases) 下载 `request-toasts-v<版本>.zip`，解压到 Codex++ 的拓展目录。

## 需要的能力

| 能力 | 内容 |
| --- | --- |
| 本地路由 | `/request-log/recent` |
| 页面脚本 | `renderer.js` |
